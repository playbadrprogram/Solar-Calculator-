# ☀️ حاسبة المنظومة الشمسية - تطبيق أندرويد

## 📋 المتطلبات

1. **Android Studio** (أحدث إصدار): https://developer.android.com/studio
2. **JDK 17** أو أحدث
3. **اتصال بالإنترنت** (لتحميل Gradle dependencies)

## 🚀 خطوات البناء

### ١. فتح المشروع
1. ثبّت Android Studio من الرابط أعلاه
2. افتح Android Studio
3. اختر **"Open an Existing Project"**
4. اختر مجلد `android` هذا

### ٢. انتظر Gradle
- سيقوم Android Studio بتحميل الـ dependencies تلقائياً
- انتظر حتى ينتهي (قد يستغرق 5-10 دقائق في المرة الأولى)
- ستظهر رسالة "Gradle sync finished" في الأسفل

### ٣. بناء APK (للاختبار)
1. من القائمة: **Build → Build Bundle(s)/APK(s) → Build APK(s)**
2. انتظر حتى ينتهي البناء
3. اضغط على **"locate"** في الإشعار لفتح مجلد الملف
4. ملف APK سيكون في: `app/build/outputs/apk/debug/app-debug.apk`
5. انسخ الملف لهاتفك وثبّته

### ٤. بناء APK للإصدار النهائي (للنشر)
1. من القائمة: **Build → Generate Signed Bundle/APK**
2. اختر **APK** → **Next**
3. أنشئ مخزن مفاتيح جديد (Key Store):
   - اضغط **"Create new"**
   - اختر مكان الحفظ وكلمة المرور
   - املأ بيانات الشهادة
4. اختر **release** كـ Build Variant
5. اضغط **Create** → ستحصل على `app-release.apk`

## 📱 نقل التطبيق للهاتف

### طريقة ١: مباشرة
1. انسخ ملف `app-debug.apk` لهاتفك
2. افتح مدير الملفات على الهاتف
3. اضغط على ملف APK
4. فعّل **"التثبيت من مصادر غير معروفة"** إذا طُلب
5. ثبّت التطبيق

### طريقة ٢: عبر USB
1. وصّل الهاتف بالكمبيوتر بـ USB
2. فعّل **"USB Debugging"** في خيارات المطور
3. في Android Studio: اضغط ▶️ **Run** → اختر هاتفك

## 🏪 النشر على Google Play

1. أنشئ حساب مطور على: https://play.google.com/console
2. ادفع رسوم التسجيل ($25 مرة واحدة)
3. ارفع ملف `app-release.aab` (Android App Bundle)
4. املأ بيانات التطبيق والصور
5. ارفع للمراجعة

## 🔧 تعديل التطبيق

### تغيير رابط الموقع
افتح `app/src/main/assets/public/` - هذه ملفات الويب المحزمة داخل التطبيق.

### تغيير اسم التطبيق
افتح `app/src/main/res/values/strings.xml` وعدّل `app_name`.

### تغيير الأيقونة
استبدل ملفات PNG في مجلدات `mipmap-*` بأيقونات بنفس الأحجام.

### تغيير ألوان الشاشة الافتتاحية
افتح `app/src/main/res/values/colors.xml` وعدّل الألوان.
