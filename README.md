أداة احترافية لحساب مكونات المنظومة الشمسية من الألواح والبطاريات والعاكس ومنظم الشحن.

3. اضغط **Deploy** مرة أخرى
4. انتظر دقيقة - ستحصل على رابط دائم!

## ✨ المميزات

- 🌞 حساب الألواح الشمسية والبطاريات والعاكس ومنظم الشحن
- 🔌 حساب الكابلات والقواطع الكهربائية
- 💰 التحليل الاقتصادي للمشروع
- 📋 قائمة المواد (BOM)
- 💾 حفظ المشاريع محلياً
- 🌙 الوضع الداكن
- 🌐 العربية والإنجليزية
- 📱 يعمل كتطبيق (PWA)
- 🇾🇪 بيانات الإشعاع الشمسي لـ 22 محافظة يمنية

## 🛠️ التشغيل المحلي

```bash
npm install
npm run dev
```
