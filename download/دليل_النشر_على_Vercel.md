# دليل نشر تطبيق حاسبة المنظومة الشمسية على Vercel (مجاني)

## الخطوة 1: إنشاء حساب GitHub
1. اذهب إلى https://github.com/signup
2. أنشئ حساباً مجانياً

## الخطوة 2: رفع المشروع على GitHub
1. بعد تسجيل الدخول في GitHub، اضغط على زر "New repository"
2. سمِّ المستودع: solar-calculator
3. اختر Private أو Public
4. اضغط "Create repository"
5. ارفع ملفات المشروع (يمكنك سحب الملفات وإفلاتها في صفحة GitHub)

## الخطوة 3: إنشاء حساب Vercel
1. اذهب إلى https://vercel.com/signup
2. سجّل باستخدام حساب GitHub الخاص بك

## الخطوة 4: نشر التطبيق
1. بعد تسجيل الدخول في Vercel، اضغط "Add New" → "Project"
2. اختر مستودع "solar-calculator" من GitHub
3. اضغط "Deploy"
4. انتظر دقيقتين حتى يتم النشر
5. ستحصل على رابط دائم مثل: https://solar-calculator-xxx.vercel.app

## الخطوة 5: مشاركة الرابط
- الرابط الذي ستحصل عليه من Vercel هو رابط دائم
- يمكنك مشاركته مع أي شخص
- التطبيق يعمل 24 ساعة بدون توقف
- Vercel مجاني للاستخدام الشخصي

---

## طريقة بديلة: النشر عبر سطر الأوامر

```bash
# تثبيت Vercel CLI
npm install -g vercel

# الذهاب لمجلد المشروع
cd /home/z/my-project

# تسجيل الدخول (سيفتح متصفح للتأكيد)
vercel login

# نشر المشروع
vercel --prod
```

بعد الانتهاء ستحصل على رابط دائم يمكنك مشاركته مع العالم!
